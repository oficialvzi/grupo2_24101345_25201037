# XSS: HTML que o servidor devolve para a listagem (curl, sem navegador)
$ curl -s localhost:8000/carros | grep XSS0A01 -A1
            <td><code>XSS0A01</code></td>
            <td>&lt;script&gt;alert(1)&lt;/script&gt;</td>

$ curl -s "localhost:8000/carros?busca=<img src=x onerror=alert(2)>" | grep "Resultado para"
    <p class="info">Resultado para <strong>&lt;img src=x onerror=alert(2)&gt;</strong>: 0 carro(s).</p>


# CSRF: POST de exclusão sem o token da sessão é recusado

Requisição inválida (token CSRF ausente ou incorreto).
  -> carro 2 continua ativo: deleted_at = NULL
